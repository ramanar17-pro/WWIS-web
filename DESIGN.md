# Design System — WWIS (Wisdom Wealth International School)

## Product Context
- **What this is:** Rebuilt marketing/admissions website for Wisdom Wealth International School, Trichy — replacing the current WordPress site.
- **Who it's for:** Prospective parents researching Cambridge-curriculum schools (directly, and increasingly via AI search/chat tools), plus current families checking admissions/tuition/curriculum info.
- **Space/industry:** K-12 international education, Cambridge curriculum, Trichy/Tamil Nadu.
- **Project type:** Marketing + admissions site, static build (Astro/Next.js-class stack per `PLANNING.md`).
- **Note:** This site's first build phase is the AI-visibility/structured-content foundation described in `PLANNING.md` (tuition, admissions, staff, curriculum, contact). This DESIGN.md governs the visual system those pages — and everything after — are built in.

## Aesthetic Direction
- **Direction:** Premium international-school editorial — **as of 2026-08-17 (third pass)**, restrained and institutional rather than "AI-native futuristic." White/neutral carries ~90%+ of the page; accent color (crimson/ember/cyan) is earned in small functional moments (CTAs, badges, icon chips, hover states) rather than washed across backgrounds. Glassmorphism is now just soft-shadow elevation on white cards; the animated gradient-glow backdrop that defined the original dark system has been dialed down to a near-invisible whisper. Bold geometric/serif type still carries the brand personality.
- **Decoration level:** Restrained-premium. Confidence now comes from typography, whitespace, and a few well-placed shadows/accents — not from a colorful or glowing backdrop. ("We don't need to shout; families trust us" — see UI/UX Inspiration Notes.)
- **Mood:** Confident, premium, unmistakably "not another templated school site," but now reads as an established, trustworthy institution rather than a tech product launch.
- **Origin:** Built through iteration in `/design-consultation` — first pass was a safe navy+serif "traditional school" direction, rejected by the founder as "old." The dark, glowing, motion-forward system that followed shipped as the first 8 homepage mockups. 2026-08-17 saw three further passes, all founder-approved: (1) dark→light background pivot on teacher feedback, (2) Innova-Schools-inspired typography/font-pairing revision, (3) Innova-Schools-inspired backdrop restraint — replacing the glow/orb/orbit-ring treatment with the quieter, section-separated, shadow-driven system described here. See Decisions Log.
- **Reference:** No external reference sites for the original dark→light pivot. From the second pass onward, Innova Schools' public homepage (innovaschools.edu.pe, the flagship of that network) has been reviewed for UI/UX inspiration only — structure/hierarchy/spacing/restraint ideas, not visual copying. See "UI/UX Inspiration Notes" below and Decisions Log.

## Typography
Font *pairing* revised 2026-08-17 (second pass) after comparing against Innova Schools — see rationale below. Same four Google Fonts families as before; roles reassigned, one new role token added.
- **Display/Hero (`--font-display`):** **Fraunces**, upright, weight 600 — promoted from italic-only accent to the hero headline serif. Big scale (44–76px), rendered with a gradient text-fill (ink navy → crimson → orange). This ties the boldest thing on the page directly back to the logo wordmark's serif gravitas, and reads as "established premium institution" rather than "tech product," which Space Grotesk (very geometric/SaaS-coded) was starting to read as once the system went light and professional.
- **Section/card headings (`--font-heading`, new):** Space Grotesk (600/700) — demoted from the hero role to structural headings (h2, h3, nav wordmark, stat numbers, FAQ summary, card icons, avatar initials, editorial ghost numerals). Still bold and geometric, now playing a secondary, structural voice under the serif hero — this serif-hero / sans-structure split is itself the main "heading hierarchy" improvement from this pass.
- **Body (`--font-body`):** Instrument Sans (400/500/600) — unchanged. Already clean/modern/highly legible; also serves the AI-crawlability goal from `PLANNING.md` (body content must stay plain, readable text regardless of chrome). Lede/intro paragraphs use weight 500.
- **Accent/quote (`--font-accent`):** Fraunces (italic, 500) — unchanged, still the sparing serif-quote treatment.
- **Labels/eyebrows (`--font-label`, new):** Instrument Sans (600, tracked uppercase) — moved off JetBrains Mono. Badges, eyebrows, nav sub-label, footer headings, form labels. Rationale: a monospace face on every small label read as "developer tool" once the system's goal shifted from "AI-native futuristic" to "professional, parent-friendly premium school" (Innova's label/tag treatment is a clean tracked sans, not mono) — dropping mono here was the single biggest tone shift available without touching layout or content.
- **Data/mono (`--font-mono`):** JetBrains Mono (400/500) — kept, but scope narrowed to where a mono face is actually earned: dashboard numerals (`.data-tile .data-num`, variant 6), log rows (variant 6), and the numbered step-index circles (`.timeline-num`). Everywhere else moved to `--font-label`.
- **Loading:** Google Fonts CDN, same four families. `<link>` request updated to also load Fraunces upright 600/700 (previously only italic 500 was loaded) — mechanical change across all 8 mockups + the gallery, no other `<head>` changes.
- **Scale:** Hero h1 44–76px (weight 600, line-height 1.08, tightened from 700/1.05 — a serif at that weight/leading reads more elegant than a heavy geometric sans did) / Section h2 30–44px / Card h3 20–23px / Body 16px / Labels 11.5–13px (tracked uppercase, weight 600, Instrument Sans). Global `-webkit-font-smoothing: antialiased` + `text-rendering: optimizeLegibility` (added 2026-08-17, first pass) still in effect.

## UI/UX Inspiration Notes (Innova Schools, 2026-08-17)
Reviewed for structural/hierarchy/restraint inspiration only — not copied, and WWIS's own 8 layouts/content were kept as-is throughout. Two research passes, both against innovaschools.edu.pe:

**Pass 2 (typography):**
- **Carried over:** clear progressive heading-size reduction and bold section headings; label/tag treatment as a clean tracked sans rather than a novelty face (drove the mono→`--font-label` move); layered card elevation for depth cues.
- **Not carried over:** Innova's real aspirational photography (WWIS has none yet) and its multi-stage content architecture (testimonials, partner-logo walls, FAQ-as-a-section) — out of scope, would mean adding new content/sections.

**Pass 3 (backdrop/visual style):** targeted follow-up fetch focused specifically on section separation, imagery treatment, color balance, and CTA styling. Findings: Innova's backgrounds are ~70%+ white/off-white with light-gray sections for "gentle contrast, no heavy borders"; **accent color appears almost exclusively in CTAs and the logo, not backgrounds** — no gradient-heavy or neon treatment anywhere; photography is restrained (1–2 images per section, consistent aspect ratios, contained in cards) rather than decorative; the overall effect is summarized as "*we don't need to shout; families trust us*."
- **Carried over:** color restraint — backdrop accent alpha cut roughly 3–5x from the previous pass, orb float/spin animation removed entirely (static only), tech-grid overlay removed, logo-plate's colored glow shrunk in favor of a neutral elevation shadow, CTA banner and photo-placeholder tiles simplified from 3-color washes to a single whisper of one accent; added a subtle hairline `border-top` between stacked sections for the "clear separation without heavy dividers" effect.
- **Not carried over:** real campus photography. WWIS has none published yet (`PLANNING.md` and the gallery sections already flag this honestly). Inventing stock/placeholder photos and presenting them as WWIS's own campus would misrepresent the school, so this pass improved the *placeholder* tiles (quieter, more intentional-looking "photography coming soon" surfaces) rather than inserting fake imagery. Real photography should replace these tiles directly once available — the components (`.gallery-tile`, `.narrative-visual`) are already structured to take a background-image or `<img>` in place of the gradient placeholder with no other markup changes needed.

## Color
- **Approach:** Expressive, **light-mode-first as of 2026-08-17.** White is the default and signature look now — dark is retained only as a historical/alternate direction, not currently in use on any mockup.
- **Paper** `#FFFFFF` — primary background (was Void Navy).
- **Surface** `#F6F7FA` — secondary/neutral surface tone (replaces Navy-2's role; used sparingly, e.g. input fills).
- **Ink** `#0E1626` — primary text (replaces `Text` `#EEF3FA`). Same navy family as the old Void Navy, repurposed as foreground instead of background.
- **Slate Fog** `#566072` — secondary/muted text (replaces `Fog Gray` `#8B9AB0`, which was ~2.5:1 on white and failed contrast; this is ~7:1).
- **Crimson Glow** `#FF2D75` — primary accent. Still used for CTAs, gradient text, and glow-orb fills, but **not** for small text on white (fails contrast at that size) — see Crimson Ink.
- **Ember Orange** `#FF9D3D` — secondary accent. Same caveat as Crimson Glow — decorative/gradient use only, not small text on white.
- **Signal Cyan** `#3DE8FF` — decorative glow-orb/gradient use only now; far too light to read as text or a focus ring on white.
- **Crimson Ink** `#C8175F` / **Ember Ink** `#B15A0E` / **Cyan Ink** `#0E7C90` / **Success Ink** `#12875A` — darkened, text-legible siblings of the four accent hues above. Used anywhere an accent color needs to be *read* on white: badge text, eyebrows, live-dot, data numerals, footer-link hover, focus rings. The rule: raw accent hues for fills/gradients/glows, `-ink` variants for text/icons/small UI on white.
- **Glass surfaces:** re-interpreted for light — fill is solid `#FFFFFF` (`#FCFCFE` for an elevated/hover variant), border `rgba(10,18,32,0.08)`, backdrop-filter blur kept only where a sticky panel sits over scrolling content (shell sidebar, split-fixed column). Definition comes from a soft ambient shadow (`--shadow-card`: `0 1px 2px rgba(10,18,32,.05), 0 10px 28px rgba(10,18,32,.08)` — strengthened slightly 2026-08-17 third pass to carry more of the "depth" job now that the backdrop itself is much quieter) rather than a dark-glow border.
- **Semantic:** success `#3DE896`/ink `#12875A`, warning `#FF9D3D`/ink `#B15A0E`, error `#FF2D75`/ink `#C8175F`, info `#3DE8FF`/ink `#0E7C90` — tinted pill fill/border keep the original low-alpha hex values (still read correctly as pale chips on white); text within each pill uses the `-ink` variant.
- **Logo handling:** the WWIS logo sits on a white plate/chip, needing its own definition (border ring + soft shadow) so it doesn't visually disappear into the page — nav chip and footer chip both carry this (small white rounded chip with a navy-tinted ring). **As of 2026-08-27, the hero no longer carries a logo plate** — the hero's right-column slot now holds a real campus photo (`.hero-visual`, see Layout and Decisions Log) instead. The `.logo-panel`/`.logo-plate`/orbit-ring CSS is left in place (unused by any page currently) rather than deleted, since it's still the correct token-driven treatment if a future page needs a plated-logo hero again.
- **Dark mode:** Retired as the active system 2026-08-17. Not deleted from history (see Decisions Log) — do not resurrect a dark toggle without a follow-up design pass.

## Spacing
- **Base unit:** 8px.
- **Density:** Comfortable-to-spacious. Section padding 100–120px vertical; hero padding 100px.
- **Scale:** 2xs(4) xs(8) sm(16) md(24) lg(40) xl(64) 2xl(100+).

## Layout
- **Approach:** Hybrid bento/glass-grid. Split hero (copy left, campus photo panel right — see `.hero-visual`, 2026-08-27; the logo panel now lives only in nav/footer). 3-column card grids for programs. Full-bleed background mesh behind all sections — as of 2026-08-17 (third pass) this is a near-invisible whisper (2 soft radial highlights behind the hero only, ~0.035–0.045 alpha) rather than a visible wash; white/neutral now does essentially all the work.
- **Grid:** 3-column card grids on desktop, collapsing to 2 then 1 on smaller breakpoints (900px, 860px).
- **Max content width:** 1240px container.
- **Border radius:** hierarchical — pills/badges/buttons `999px`, cards `20px`, large panels `28–32px`.
- **Section separation (added 2026-08-17, third pass):** a subtle 1px hairline (`rgba(10,18,32,0.05)`) on top of every `.section`/`.section-tight` block — Innova-style "clear separation without heavy dividers." Suppressed on the section immediately after `.hero` to avoid a stray line directly under the hero.
- **Nav:** Sticky, blurred glass background (`backdrop-filter: blur(16px) saturate(160%)`), border-bottom hairline, white surface (`rgba(255,255,255,0.94)`, `0.99` when scrolled). Approved as a one-off exception on 2026-08-13 when the rest of the page was still dark; the whole page is white now, so the header is simply consistent with the page.

## Motion
- **Approach:** Restrained as of 2026-08-17 (third pass) — motion now supports content (entrances, hover feedback) rather than running as ambient background animation. See Decisions Log for what was removed and why.
- **Background:** Two soft radial highlights behind the hero only (no orbs elsewhere), fully static — no perpetual float. The `.orb`/`.bg-grid` elements from the original dark system are still present in code (harmless, `display:none`/near-zero-alpha) but contribute effectively nothing visually now.
- **Hero:** Staggered fade-up entrance (badge → headline → paragraph → CTAs → logo panel, ~100ms stagger) — kept, this is normal premium-site motion, not the "futuristic" cue that was dialed back.
- **Logo panel:** Orbit rings retired 2026-08-17 (third pass) — dashed spinning rings read as sci-fi chrome. The logo plate now relies on a soft neutral elevation shadow (plus a small warm glow, ~0.06 alpha) instead.
- **Interactive:** Hover feedback kept but calmed — primary/secondary buttons use a normal elevation shadow with only a light accent tint (was a wide colored glow bloom), gradient border reveal on card hover, subtle `translateY(-6px)` lift on cards, pulsing "live" status dot (small, functional, kept).
- **Easing:** `cubic-bezier(0.16, 1, 0.3, 1)` (ease-out) for entrances and hovers.
- **Performance/accessibility constraint:** All motion must be transform/opacity-only (GPU-cheap), and every animation must respect `prefers-reduced-motion: reduce`. This matters more than usual here because `PLANNING.md` prioritizes fast load and plain-HTML AI-crawlability.
